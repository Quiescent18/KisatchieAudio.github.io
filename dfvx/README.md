# dfVX — Windows VST3 downloads

This directory is used to publish **dfVX**, the Windows VST3 vocal effects plugin by Kisatchie Audio.

## Install

1. Download the Windows VST3 ZIP from the dfVX release page.
2. Unzip it and close your DAW.
3. Copy the entire `dfVX.vst3` directory to `C:\Program Files\Common Files\VST3`.
4. Restart your DAW and rescan its VST3 plug-ins.

The Windows distribution contains the **VST3 bundle**, a plain-text **README**, and **release notes**. The standalone GUI test harness and development outputs (`.lib`, `.exp`) are not included.

## Release information

Current prepared build: **v0.1.0** (Windows x64). GitHub publishes the ZIP and its SHA-256 checksum when the package is uploaded under `dfvx/release-files/`. Check the Releases section for downloadable assets. The binaries are not digitally signed.

## Support

For installation problems, confirm that the DAW supports VST3, that you copied the entire `.vst3` bundle, and that the DAW rescan has completed.
