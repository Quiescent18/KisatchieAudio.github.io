Windows VST3 installation

  1. Download and extract the dfVX Windows ZIP once available.
  2. Close your DAW. Copy the complete dfVX.vst3 folder into C:\Program Files\Common Files\VST3.
  3. Reopen your DAW and rescan VST3 plugins if needed. Find dfVX by Kisatchie Audio.

Keep the VST3 bundle intact. Do not install build artifacts, .exp files, or .lib files.
